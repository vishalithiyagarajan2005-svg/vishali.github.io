## 5. GCP Dataset ETL & Airflow Pipeline

A practical ETL workflow using a dataset obtained from GCP.

The dataset was downloaded as a CSV file, read and processed using Python,
and transformed before loading the final data into MySQL.

The workflow was then integrated with Apache Airflow by creating and
configuring an Airflow DAG to manage the data pipeline.

The Airflow workflow provides an automated way to execute the data
processing pipeline and produce the final dataset output.

### Key Concepts
